# Computer Architecture – Problem Solving Group 1

Course: Computer Architecture  
Course Code: 25AIM34

## Q1 – Signed Binary Arithmetic
Uses 8-bit 2's complement representation for:
- 25 + 18
- (-25) + (-18)

## Q2 – Logical Shift Operations
Uses 8-bit binary numbers for:
- Logical left shift of 10110110 by 2 positions
- Logical right shift of 10101000 by 2 positions

## Files
- `q1_twos_complement.py` – Q1 program
- `q2_logical_shift.py` – Q2 program
- `result_screen.png` – result/output screen
- `output.txt` – program output

## Expected Results
- Q1(a): `00101011` = 43
- Q1(b): `11010101` = -43
- Q2(a): `11011000` = 216
- Q2(b): `00101010` = 42

## Run
```bash
python3 q1_twos_complement.py
python3 q2_logical_shift.py
```
